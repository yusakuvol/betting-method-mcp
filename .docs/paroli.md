# パーレー法（Paroli Method）

## 概要

パーレー法（逆マーチンゲール法）は、勝った時に賭け金を倍にする攻撃的な戦略です。連勝時の利益を最大化し、目標連勝数に達したらリセットします。負けた場合は即座に初期賭け金に戻るため、損失が限定的です。

## 仕組み

### 基本ルール

1. **初回**: `baseUnit` を賭ける
2. **勝った場合**: 賭け金を2倍にする
3. **目標連勝数に達した場合**: `baseUnit` にリセット（1サイクル完了）
4. **負けた場合**: いつでも `baseUnit` にリセット

### 計算式

```
勝ち後の賭け金 = currentBet * 2
負け後の賭け金 = baseUnit
```

### 例（baseUnit = 10、目標連勝数 = 3）

| ラウンド | 賭け金 | 結果 | 累積損益 | 連勝数 |
|---------|--------|------|---------|-------|
| 1       | 10     | 勝ち | +10     | 1     |
| 2       | 20     | 勝ち | +30     | 2     |
| 3       | 40     | 勝ち | +70     | 3→完了 |
| 4       | 10     | 負け | +60     | 0     |
| 5       | 10     | 勝ち | +70     | 1     |

## パラメータ

### 必須パラメータ

- **baseUnit** (基本賭け金単位): 1単位あたりの金額

### オプションパラメータ

- **targetWinStreak** (目標連勝数): リセットする連勝数（デフォルト: `3`）

## State定義

```typescript
interface ParoliState {
  baseUnit: number;           // 基本賭け金単位
  currentBet: number;         // 現在の賭け金
  targetWinStreak: number;    // 目標連勝数
  winStreak: number;          // 現在の連勝数
  totalProfit: number;        // 累積損益
  sessionActive: boolean;     // セッション状態
  cyclesCompleted: number;    // 完了サイクル数
  roundCount: number;         // ラウンド数
}
```

## MCPツール

- **paroli_init** - セッション初期化
- **paroli_record** - 勝敗記録（`"win"` または `"loss"`）
- **paroli_status** - 現在の状態確認
- **paroli_reset** - セッションリセット

## 注意事項

- 連勝しないと利益が出ない構造であり、勝率50%のゲームでは3連勝の確率は12.5%
- 損失は常に `baseUnit` に限定されるためリスクは低い
- 目標連勝数を高く設定しすぎると達成が困難になる
- 教育・研究目的のツールであり、実際の賭博での利益を保証しない
