# フィボナッチ法（Fibonacci Method）

## 概要

フィボナッチ法は、フィボナッチ数列（1, 1, 2, 3, 5, 8, 13...）を賭け金の基準に使う戦略です。負けたら数列を1つ進み、勝ったら2つ戻ります。マーチンゲール法より緩やかな増加で、リスクを抑えた累進戦略です。

## 仕組み

### 基本ルール

1. **初回**: フィボナッチ数列のインデックス0（= 1）から開始
2. **負けた場合**: インデックスを1つ進める（賭け金増加）
3. **勝った場合**: インデックスを2つ戻す（最小は0）
4. **終了条件**: インデックスが `maxIndex` を超えた場合

### フィボナッチ数列

```
インデックス:  0  1  2  3  4  5   6   7   8
数列:         1  1  2  3  5  8  13  21  34
賭け金 = fibonacci[index] * baseUnit
```

### 例（baseUnit = 10）

| ラウンド | Index | 賭け金 | 結果 | 累積損益 |
|---------|-------|--------|------|---------|
| 1       | 0     | 10     | 負け | -10     |
| 2       | 1     | 10     | 負け | -20     |
| 3       | 2     | 20     | 負け | -40     |
| 4       | 3     | 30     | 勝ち | -10     |
| 5       | 1     | 10     | 勝ち | 0       |

## パラメータ

### 必須パラメータ

- **baseUnit** (基本賭け金単位): 1単位あたりの金額

### オプションパラメータ

- **maxIndex** (最大インデックス): 数列の上限位置（デフォルト: `10`）

## State定義

```typescript
interface FibonacciState {
  baseUnit: number;           // 基本賭け金単位
  currentBet: number;         // 現在の賭け金
  currentIndex: number;       // 現在のフィボナッチインデックス
  maxIndex: number;           // 最大インデックス
  totalProfit: number;        // 累積損益
  sessionActive: boolean;     // セッション状態
  reachedLimit: boolean;      // 上限到達フラグ
  roundCount: number;         // ラウンド数
}
```

## MCPツール

- **fibonacci_init** - セッション初期化
- **fibonacci_record** - 勝敗記録（`"win"` または `"loss"`）
- **fibonacci_status** - 現在の状態確認
- **fibonacci_reset** - セッションリセット

## 注意事項

- マーチンゲール法より緩やかだが、連敗時は賭け金が指数的に増加する
- 勝っても2つしか戻らないため、損失回収に複数回の勝ちが必要
- `maxIndex` を設定して最大賭け金を制限すること
- 教育・研究目的のツールであり、実際の賭博での利益を保証しない
