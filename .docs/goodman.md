# グッドマン法（Goodman 1-2-3-5 Method）

## 概要

グッドマン法は、1-2-3-5の固定数列に従って連勝時に賭け金を増やす戦略です。連勝の利益を最大化しつつ、負けた場合は即座にリセットすることでリスクを抑えます。攻守バランスの良い手法として知られています。

## 仕組み

### 基本ルール

1. **初回**: `1 * baseUnit` を賭ける
2. **連勝時**: 数列 `1 → 2 → 3 → 5` の順に賭け金を増やす
3. **5の後も勝ち続ける場合**: `5 * baseUnit` を維持
4. **負けた場合**: いつでも `1 * baseUnit` にリセット

### 数列と賭け金

```
ステップ1: 1 * baseUnit（初期・リセット後）
ステップ2: 2 * baseUnit（1連勝後）
ステップ3: 3 * baseUnit（2連勝後）
ステップ4: 5 * baseUnit（3連勝後、以降維持）
```

### 例（baseUnit = 10）

| ラウンド | ステップ | 賭け金 | 結果 | 累積損益 |
|---------|---------|--------|------|---------|
| 1       | 1       | 10     | 勝ち | +10     |
| 2       | 2       | 20     | 勝ち | +30     |
| 3       | 3       | 30     | 勝ち | +60     |
| 4       | 4       | 50     | 負け | +10     |
| 5       | 1       | 10     | 勝ち | +20     |

## パラメータ

### 必須パラメータ

- **baseUnit** (基本賭け金単位): 1単位あたりの金額
  - 例: `10`, `100`, `1000`

## State定義

```typescript
interface GoodmanState {
  baseUnit: number;           // 基本賭け金単位
  sequence: number[];         // 固定数列 [1, 2, 3, 5]
  currentStep: number;        // 現在のステップ（0始まり）
  currentBet: number;         // 現在の賭け金
  winStreak: number;          // 現在の連勝数
  totalProfit: number;        // 累積損益
  sessionActive: boolean;     // セッション状態
  cyclesCompleted: number;    // 完了サイクル数
  roundCount: number;         // ラウンド数
}
```

## MCPツール

- **goodman_init** - セッション初期化
- **goodman_record** - 勝敗記録（`"win"` または `"loss"`）
- **goodman_status** - 現在の状態確認
- **goodman_reset** - セッションリセット

## 注意事項

- 連勝しないと利益が出にくい構造である
- 負けた時のリセットにより大きな損失は避けられるが、連敗時は損失が蓄積する
- 2倍配当ゲーム（バカラ、ルーレットの赤黒等）に適している
- 教育・研究目的のツールであり、実際の賭博での利益を保証しない
