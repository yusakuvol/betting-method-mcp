# モンテカルロ法（Monte Carlo Method）

## 概要

モンテカルロ法は、数列を用いたベッティング戦略です。数列の最初と最後の数字を足して賭け金を決定し、勝敗に応じて数列を操作します。数列の要素が0〜1個になるとセッションが完了し、理論上は利益が出る仕組みです。

## 仕組み

### 基本ルール

1. **初期数列を設定**: `[1, 2, 3]`
2. **賭け金の計算**: `(最初の数 + 最後の数) * baseUnit`
   - 数列が1要素の場合: `その数 * baseUnit`
3. **勝った場合**: 数列の最初と最後の要素を削除
4. **負けた場合**: 賭けた単位数を数列の末尾に追加
5. **終了条件**: 数列が空または1要素以下になったら完了

### 計算式

```
賭け金 = (sequence[0] + sequence[sequence.length - 1]) * baseUnit
```

### 例

| ラウンド | 数列        | 賭け金     | 結果 | 累積損益 |
|---------|------------|-----------|------|---------|
| 1       | [1, 2, 3]  | 4 * base  | 負け | -4      |
| 2       | [1,2,3,4]  | 5 * base  | 勝ち | +1      |
| 3       | [2, 3]     | 5 * base  | 勝ち | +6      |
| 4       | (空)        | -         | 完了 | +6      |

## パラメータ

### 必須パラメータ

- **baseUnit** (基本賭け金単位): 1単位あたりの金額
  - 例: `10`, `100`, `1000`

## State定義

```typescript
interface MonteCarloState {
  sequence: number[];       // 現在の数列
  baseUnit: number;         // 基本賭け金単位
  currentBet: number;       // 現在の賭け金
  totalProfit: number;      // 累積損益
  sessionActive: boolean;   // セッション状態
  roundCount: number;       // ラウンド数
  statistics: object;       // 統計情報
}
```

## MCPツール

- **montecarlo_init** - セッション初期化
- **montecarlo_record** - 勝敗記録（`"win"` または `"loss"`）
- **montecarlo_status** - 現在の状態確認
- **montecarlo_reset** - セッションリセット
- **montecarlo_statistics** - 統計レポート表示

## 注意事項

- 負けが続くと数列が長くなり、賭け金が増大する
- セッション完了時の利益は保証されるが、途中離脱では損失の可能性がある
- 3倍配当ゲーム向けに設計された手法だが、2倍配当でも使用可能
- 教育・研究目的のツールであり、実際の賭博での利益を保証しない
